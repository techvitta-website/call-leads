Before you start

Check Vercel has deployed the latest build. A lot has shipped today — the newest commit is 6ef5b47. Open Vercel → Deployments and confirm the top entry is Ready and matches. If the site looks like it did this morning, that's why.

Test in this order

Each step sets up the next

1 · Does the basic app work was broken

  1. Sign in as manager@techvitta.in. You should land on the Manager dashboard.
  2. Go to Leads. The project dropdown should list Drones CRM, Kanchii Batch 2, Derma Clinic CRM, HRMS — this was empty before; every project had a null owner so the security rule hid them all.
  3. Confirm the toolbar buttons are coloured, not greyed out. Add Lead should work even with "All Projects" selected.

2 · Find real businesses new

The most immediately useful feature. Real companies with real phone numbers.

  1. Leads → Find Businesses (teal button).
  2. Project Derma Clinic CRM, category Clinics & doctors, city Hyderabad, then Search.
  3. Expect roughly 26 results, ~25 with phone numbers. I got IDEA Clinics, Sri Shankara Nethralaya, Aswini Diabetic Centre.
  4. Untick a few, then Import. They appear in Leads tagged OpenStreetMap.

Worth also trying: Schools in Hyderabad, Hotels in Vijayawada, Factories in Pune. Switch the Source dropdown to Google Places to see it return results you can't import — that's deliberate, explained below.

3 · AI lead generation rebuilt

  1. Leads → AI Generate. Pick project HRMS.
  2. The brief is pre-filled from the project. Set Industry Manufacturing, Region Telangana & Andhra Pradesh, cities Hyderabad, Vijayawada.
  3. Tick seniority C-Suite, Head of, Director; department Human Resources, Operations; headcount 101-200, 201-500.
  4. Open Advanced filters and try an exclusion like staffing agency, consultancy.
  5. Generate. Expect ~20 seconds.

Contact fields will be blank, on purpose. You'll see "Ask for: Head of Human Resources" and a research hint instead of a name and number. The earlier version invented them — it produced six leads with the phone numbers 9876543210, …211, …212. Every one useless. It now returns only what it actually knows, and the companies improved as a side effect: real firms like Virchow Biotech and Sri Chakra Cements instead of invented ones.

4 · AI scoring was broken

Leads → AI Score → score the visible leads → Apply. Then refresh the page. The scores should still be there. Previously they vanished, because they were only held in memory and never written to the database — which also meant the Min/Max Score filter never saw them.

5 · Saved searches and lists new

  1. On Leads, set some filters — status Qualified, a city, a priority.
  2. Click Save current filters, name it. A chip appears in the "Saved" row at the top.
  3. Change the filters, then click the chip. It restores them.
  4. Tick some leads → Add to List → create a new list.
  5. Sidebar → Lists & Searches to see both.

The distinction matters: a saved search re-runs live so new matching leads appear on their own; a list is the exact leads you picked and never changes by itself.

6 · Sequences new

  1. Sidebar → Sequences → New sequence.
  2. Click a template — "New inbound lead follow-up" gives you WhatsApp day 0, call day 2, email day 5, task day 12.
  3. Save it. Then on Leads, tick some leads → Add to Sequence.
  4. The first step fires within 15 minutes and becomes a task for whoever owns the lead.

It stops on its own when the deal closes or when anyone logs activity against the lead.

8 · User management important fix

Sidebar → Manage Users. Each person now has a Receives new leads toggle.

This one would have quietly wasted your leads. You have 13 salesman accounts but only two real people. Round-robin assigns to whoever has the fewest open leads — shiva had 130, the eleven test accounts had zero. So every automated lead would have gone to test4@gmail.com and none to your actual salesperson. The toggle is off for all eleven leftovers.

9 · The salesperson view

Sign out, sign in as salesman@techvitta.in. You should see 5 leads and a restricted menu — no automations, no user management. Confirms the permission rules hold.

What's deliberately restricted

Google Places results can be viewed but not imported. This isn't a bug. Scraping Google Maps is prohibited by their terms, which name "copy and save business names, addresses" as an example. And their official API doesn't help: Google's own guide for this exact use case says storing Places contact data in a CRM isn't permitted — only their internal place ID may be kept.

OpenStreetMap is the importable source because its licence (ODbL) permits commercial use and permanent storage with attribution. That's why "Find Businesses" defaults to it.
